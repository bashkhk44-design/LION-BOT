# BOSS EAGLE BET — HEAD Panel

لوحة HEAD مستقلة عن بوت Telegram، بواجهة عربية RTL وتصميم أسود/ذهبي متجاوب مع الهاتف.

## التشغيل
يتطلب Node.js 20 أو أحدث.

1. ثبّت اعتماديات المشروع: `npm install`
2. عيّن متغيرات البيئة التالية في إعدادات الاستضافة:
   - `HEAD_USERNAME`: اسم دخول HEAD.
   - `HEAD_PASSWORD`: كلمة مرور قوية لا تقل عن 12 محرفاً.
   - `HEAD_SESSION_SECRET`: قيمة عشوائية سرية لا تقل عن 32 محرفاً.
   - `PORT`: المنفذ الذي توفره الاستضافة (اختياري؛ الافتراضي 3001).
   - `NODE_ENV=production` عند النشر خلف HTTPS.
3. شغّل اللوحة: `npm run head`

يمكن توليد سر جلسة من Termux بالأمر:
`node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"`

## البيانات والصلاحيات
- تُحفظ سجلات الهيكل الهرمي في `head-panel/data/head-data.json` عند أول تشغيل.
- لا يتم تخزين كلمات مرور الوكلاء في هذه النسخة؛ إدارة الدخول الفعلية للوكلاء وربط اللاعبين والبوت مرحلة مستقلة.
- HEAD وحده ينشئ رؤساء الوكلاء والوكلاء والكاشير، ويمكنه تفعيل الحسابات أو إيقافها.
- الكاشير لا يمكن أن يكون له تابع، ولا يمكن إنشاء حساب تابع من دون مسؤول أعلى.
- سجل النشاطات يحتفظ بآخر 200 حدث.
- لا توجد أي قراءة أو كتابة لقاعدة بيانات البوت في هذه النسخة.

## النشر
أنشئ تطبيقاً مستقلاً في الاستضافة من الفرع `head-panel-v1`، واجعل أمر التشغيل `npm run head`، واضبط متغيرات البيئة أعلاه. لا تغيّر تطبيق البوت الحالي ولا أمر تشغيله.
